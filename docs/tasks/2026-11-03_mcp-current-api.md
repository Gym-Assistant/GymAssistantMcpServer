# MCP: подключение нового пользователя и текущий API

## Цель и границы

Дать другу владельца воспроизводимый путь подключения собственного ИИ к аккаунту.
База: main d62e3f5, опубликованный .NET Docker0.6.0; production API по текущему
START_HERE — BE0.69.0/1b79fcf. Python и .NET — разные реализации, не выдавать проверку
одной за проверку другой. Production только чтение; записи только синтетические.
Не менять backend, токены пользователей, права registry, оплаты и чужие MCP-установки.

## Изменения

QUICKSTART — основной путь без Docker/.NET/GitHub Packages, закрытый env-файл,
минимальные scopes, абсолютная команда stdio, отличия от встроенного Джима,
проверка аккаунта, обновление/отзыв и безопасное поведение после неизвестного исхода записи.
README больше не предлагает неработающий анонимный latest как основной путь.
scripts/check-readonly.py проверяет фиксированный набор чтений и не печатает ответы/токены.

## Статусы и ограничения

коннектор пригоден для описанного сценария. UI конкретного стороннего клиента,
Windows/Linux и аккаунт друга отдельно не проверены. Приложение/биллинг не менялись.
