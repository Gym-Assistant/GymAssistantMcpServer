# T3. Ошибка старта из плана в MCP

## Контекст
Backend возвращает 403 plan_workout_start, если новому старту из плана не хватает доступа.

## Изменения
Python-клиент сохраняет безопасный признак ошибки и показывает краткое объяснение. Детали ответа сервера остаются скрыты.

## Проверка
Синтетический HTTP-ответ и вызов инструмента через stdio-совместимый интерфейс.
