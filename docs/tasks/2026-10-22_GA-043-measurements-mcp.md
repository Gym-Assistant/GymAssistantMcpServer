# GA-043 — новые измерения в MCP

## Контекст

Техническое расширение каталога добавляет время, дистанцию, интервалы, помощь,
сопротивление и дополнительные параметры подхода. Бот должен читать и составлять
такие планы без потери данных, сохраняя смысл прежних веса/повторов.

## Исходное состояние

Фактически настроен `~/tools/gymassistant-mcp/run.sh` (Python), отдельный .NET MCP
не является этим подключением. Python чтение планов/упражнений возвращает исходный
JSON, но сводка тренировок отбрасывала `measurement`, а вход планов запрещал его и
требовал минимум один повтор. Синтетическая запись 120 с / 500 м становилась `0 кг × 0`.
.NET MCP использует `GymAssistant.Client 0.13.0`, в котором нового контракта нет.
Последний опубликованный пакет клиента — 0.15.0 от 20 октября. Требуется 0.16.0,
сгенерированный после подтверждения backend 0.17.1.

## Выполнено локально

- Python: типизированные измерения всех восьми форматов для создания и дополнения
  планов, проверка единиц/диапазонов/совместимости полей. Старый ввод сохраняется.
- Чтение тренировок сохраняет измерения целиком. 1RM/объём не включают явно
  несиловые форматы и не переосмысляют старые записи по текущему типу упражнения.
- Установщик резервирует изменяемые файлы, проверяет сигнатуры и повторную установку.
  Права и ключи не меняются, автоматических POST-повторов нет.
- Python-контракты добавлены в CI; установка в рабочий MCP пока не выполнена.

## Проверка

- 43 Python unit tests PASS.
- Настоящий stdio на синтетическом API: создание смешанного плана, чтение новых
  измерений, добавление дней с сохранением прежнего дерева, защита рекордов PASS.
- Пять резервных копий подтверждены до POST; 13 неверных запросов остановлены;
  прежние девять схем команд и Health сохранены. Production-запросов — 0.
