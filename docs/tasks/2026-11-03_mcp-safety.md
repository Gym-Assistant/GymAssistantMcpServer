# Защита локального MCP от случайной нагрузки · кандидат

Цель владельца: сделать использование MCP безопаснее для сайта и приложения, сохранив чтения и согласованное создание/дополнение планов. Baseline — опубликованный `v0.7.0` / `de233063e67c35ece92f89943d724bbd718de178`; кандидат — незакоммиченное дерево `feature/mcp-safety` в `.worktrees/mcp-safety`. Quickstart подготовлен для ещё не опубликованного `v0.7.1`.

В scope: защита одного Python-процесса, все имена инструментов, общий HTTP-транспорт, подготовленный remote auth, payload/страницы/копии, необязательный режим только чтения; синтетические проверки и обычные безопасные GET. Вне scope: backend deployment, публичный HTTP, изменение PAT/scopes, платежи и production-записи. Владелец 03.11 явно разрешил commit/PR/CI/merge/tag и локальный выпуск v0.7.1. Backend deployment и публичный HTTP этим разрешением не охвачены.

Критерии: отказ до сети при исчерпании квот; слоты освобождаются после исключений; aliases/новый transport/другой Health PAT не обходят общий лимит; незавершённый каталог не используется для записи; локальный отказ не объявляется неизвестным исходом отправки; обычный план и append сохраняют старое дерево и однократную отправку. Предельные значения — начальные ограничения MCP, не результат нагрузочной приёмки production.

## Изменения

- Общий для процесса RequestGuard: 120 запросов за скользящие 60 секунд, до 12 записей, 2 одновременно. Нет очереди/повторов. Окно допускает burst до доступного остатка квоты; это не равномерное распределение нагрузки.
- Один tools/call: 64 API-запроса, 90 секунд до допуска очередного HTTP-запроса, timeout самого HTTP 30 секунд. ContextVar переносится в рабочий поток; счётчик защищён Lock. После 429/503 — общая пауза 30–300 секунд по Retry-After (секунды или HTTP-дата).
- Каталог/замеры — до 50 страниц, затем явный отказ без усечённых результатов. История тренировок сохраняет прежние 5000/50 страниц.
- Исходящий UTF-8 JSON до 1 МиБ, дерево глубиной до 20 и 100000 узлов, строки до 10000 символов. Typed план: 31 день, 50 упражнений/день, 50 подходов/упражнение, 2000 подходов всего. Превышение не приводит к POST.
- Копия перед append до 4 МиБ, общий каталог копий до 100 МиБ; существующие файлы не удаляются. При позднем отказе POST копия может остаться; объём ограничен, запись в API не выполняется.
- GYM_MCP_READ_ONLY=1 блокирует все инструменты записи до запуска и повторно проверяется транспортом. По умолчанию режим работы с планами сохранён. Этот флаг не заменяет узкие scopes PAT.

## Граница защиты

Это защита от случайной активности одного процесса. Перезапуск процесса, несколько процессов и прямые API-вызовы обходят его локальные квоты. Для общей защиты сайта нужен следующий отдельно согласуемый пакет backend/reverse proxy: квоты по PAT и аккаунту, общая конкурентность тяжёлых endpoint, лимиты размера/времени, 429 с Retry-After и наблюдаемость; проверить на изолированном стенде вместе с обычным iPhone/Watch/web трафиком. Локальный MCP нельзя объявлять глобальной защитой от DDoS. Публичный HTTP остаётся подготовленным прототипом до отдельной приёмки.
