# GymAssistant MCP

Один поддерживаемый сервер на Python 3.14: локальный stdio с 15 исходными инструментами и 44 совместимыми именами прежнего .NET MCP. Он читает текущий API без потери `measurement: null`, а создание и дополнение планов выполняет без автоматического повтора записи. Исходники, зависимости и установка доступны без приватного GitHub Packages или GHCR.

**[Подключение нового пользователя](QUICKSTART.md)** — единственная инструкция по установке, токену, проверке и откату.

Удалённый Streamable HTTP адаптер использует те же инструменты, проверяет PAT на каждом запросе и изолирует пользователей. Он подготовлен только для изолированных проверок и **не опубликован**. Схема включения и открытые gates — [план удалённого MCP](docs/tasks/2026-11-03_mcp-unification.md).

Сырой upsert, удаление и публикация из старого набора имён по умолчанию заблокированы. Для ранее настроенного клиента их можно явно включить локально через `GYM_ENABLE_LEGACY_WRITES=1`; права токена и проверки владельца остаются обязательными. Рекомендуемый путь записи планов — `gym_create_plan` и `gym_append_plan_days`.

Backend остаётся источником прав, scopes, владельца и подписочного entitlement. Коннектор не назначает тариф и не хранит общие пользовательские ключи. Модель доступа к платному API ещё не активирована на production; наличие инструмента сейчас не является обещанием уже включённого биллинга.
